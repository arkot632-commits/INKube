# My Skill

This skill provides a simple starter structure for building reusable automation and task support.

## When to use this skill

Use this skill as a template when you need to:
- define a new reusable capability,
- keep instructions alongside supporting files,
- organize scripts, documentation, and assets in one place.

## Instructions

1. Start by understanding the request and the intended outcome.
2. Keep the skill focused on one clear purpose.
3. Put executable automation in `scripts/`.
4. Store supporting guidance in `references/`.
5. Keep templates and static resources in `assets/`.
6. Validate changes with the smallest relevant check.

## Layout

- `SKILL.md`: metadata and operational guidance for the skill.
- `scripts/`: executable scripts or helper commands.
- `references/`: documents and reference material.
- `assets/`: templates, examples, and supporting resources.
